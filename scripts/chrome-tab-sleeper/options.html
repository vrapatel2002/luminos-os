Hard cap — when an AI model is loaded
luminos-ram scans for a resident llama-server / .gguf / MoE process and says so on /meminfo. While one is loaded, only the tabs below stay in memory — everything else sleeps immediately, with no grace period.
The tab you are looking at, plus the rest of the budget. Default 2.
This is the background-music slot. If more tabs are making noise than there are slots, the most recently opened one survives and the others sleep.
Switch to another app and leave it, and even the tab you were reading sleeps. Tabs playing audio and "never sleep" tabs still survive. The delay is there so glancing at a terminal does not blank the page you were on.
⚠️ This is a deliberately blunt rule. It counts tabs, not megabytes — the third tab sleeps whether it holds 8 MB or 800 MB, and it does not check how much the model actually needs. Built this way to be provably correct in one pass; the measured version is future work.
