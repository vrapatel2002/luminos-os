## HIGH

**H2 — Show Desktop is not detected.** `main.js:75` tests `w.hidden`. In KWin 6.7 `hidden` is `Window::isHidden()`, used for auto-hide panels and X11 internal hiding. Show Desktop sets a different flag, `hiddenByShowDesktop` (libkwin.so.6 metaobject strings contain `hiddenByShowDesktop`, `hiddenByShowDesktopChanged`, `isHiddenByShowDesktop`, `setHiddenByShowDesktop`). So during Show Desktop every app window has `hidden=false`, `onCurrent=true`, nothing covers it, and the desktop window takes focus: that is exactly the live log at 14:30:28, Claude `why=f=1.00` while the PM's kwin-eval toggled Show Desktop. Result: Show Desktop releases every app to full speed instead of f=0.
Fix (2 lines): `main.js:75` → `return desk && act && !w.hiddenByShowDesktop;` and `main.js:124` → `w.hiddenByShowDesktopChanged.connect(schedule);`. Verify first with kwin-eval while Show Desktop is on: `print(workspace.windowList().map(function(w){return w.caption+" "+w.hiddenByShowDesktop}))`.

**H3 — the wallpaper is frozen before it has painted, so it shows black until the desktop is clicked.** `WebMode.qml:240` fires `applyState` as soon as main.qml binds `shouldPlay=false` (`main.qml:422`), i.e. while the page is still loading. `applyState` grabs a blank page, hides the view and freezes it; a frozen renderer does not finish loading. Live evidence: plasmashell restarted 14:27:49 with Claude focused; the page's first console lines (`THREE.WebGLRenderer`, `Particulate.js`) appear only at 14:30:27.96, 30 ms after the Show Desktop eval made `shouldPlay` true. For 2.5 minutes the "frozen frame" was an unpainted page. This happens at every plasmashell start, every login with a focused restored window, and every wallpaper change (see M6).
Fix (≈4 lines): in `applyState` add before the freeze branches `else if (web.loading) { /* onLoadingChanged re-applies */ }`; and at `WebMode.qml:150` replace `web.applyState()` with `settle.restart()` plus `Timer { id: settle; interval: 1000; onTriggered: web.applyState() }` so the page gets one second to paint its first frame before it is grabbed. The one-second Active window is the price of a real frame.
