Desktop settings — redesign

The window from right-click → Configure Desktop and Wallpaper. Everything is clickable.

What changes

  • Sidebar like System Settings: rows with a round icon, a title and a one-line hint, search on top — instead of six big boxes.
  • Wallpaper page starts with what you have now: a preview of your desktop, the file name, and the actions next to it.
  • Installed wallpapers are a proper grid with a tick on the one in use, a "Live / Video / Web" tag, and an Add tile.
  • Settings in cards with switches (power, sound, interaction) instead of a long form of checkboxes; rarely used ones fold under "More options".
  • Mouse actions, Location, Icons, Filter get the same rows-and-switches style; Icons shows a live mini preview.
  • OK / Apply / Cancel become a small bar that only appears when something changed (Apply keeps the window, Close asks if you have unsaved changes).

What it touches

  • The window frame + sidebar: plasma-desktop — already a Luminos fork (DECISION 140), so this is one more patch there.
  • The wallpaper page: our own Luminos Live Wallpaper plugin's settings page.
  • Mouse/Location/Icons/Filter pages: same plasma-desktop fork (Folder View settings).
  • Every setting keeps its current meaning and storage — only the look and grouping change.
  • Other wallpaper types (Image, Slideshow, Colour…) keep KDE's own page inside the new frame.
