Luminos Media

Prototype. One window for every photo and video. Try it: arrow keys or the side buttons move through the folder, Space plays a video, scroll or +/− zooms a photo, drag to pan, I opens details, F fills the window. Controls fade when you stop moving the mouse.

Details

What opens in itPhotos: JPG, PNG, HEIC/HEIF, AVIF, JXL, WebP, GIF (animated), TIFF, BMP, SVG, PSD, camera RAW. Video: MP4, MKV, WebM, MOV, AVI, MPEG, 3GP, TS. Set as the default for all of them.
How light it isMeasured on your G14: a photo ~115 MB, 0 % CPU when still. 1080p video ~145 MB, ~6 % CPU; 4K HEVC ~325 MB, ~9 %, decoded on the AMD 780M. The NVIDIA card never wakes. Closing the window ends the process: nothing stays in RAM.
Not in it on purposeNo library, no editing, no tags, no background indexer, no thumbnail cache on disk. The folder strip makes small thumbnails only while it is open and drops them when it closes.
